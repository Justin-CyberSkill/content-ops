# Content Ops App

One place where I plan social media content with agents, and the team follows the plan
and timeline to create and publish it. Always the latest state, with no more messages
and URLs to keep track of.

**Principles:** we own our data, with no vendor lock-in · agents propose, people decide · ship small, improve from real use

## v1: build first

1. **Content plan**: for each content: goal (what we want and why), target platforms, content type
   (motion video, live, short, text post, quiz…), content idea, timeline (day, golden time),
   assigned member, status, asset links, comments
2. **Team sign-in**: email + password, invite-only (I add members; no public sign-up)
3. **Views**: calendar, and "My tasks" for each member
4. **Agent integration (API/MCP)**: agents generate content ideas into the plan as _Proposed_;
   I approve them

**Done when:** I no longer message the plan to each member or the group, and the team
checks one place for the latest state.
