# Decisions

Where this project differs from [the baseline](baseline/README.md), newest last: what, the date it was approved, and why.
- **i18n: next-intl**, 2026-10-23. Vietnamese (default) and English, following [the i18n recipe](baseline/recipes/i18n.md). Every route sits under `[locale]` (`/vi/content`), so each screen prerenders per language; the `NEXT_LOCALE` cookie remembers the choice.
- **Agent API keys: `@better-auth/api-key`** (MIT), 2026-10-23. Hashed, rate limited per key and made by admins under Agents. `/api/agent` and `/api/mcp` accept only keys an admin owns. `enableSessionForAPIKeys` stays off, so a key never acts as a signed-in user.
- **MCP server: `@modelcontextprotocol/sdk`** (MIT, the official TypeScript SDK), 2026-10-24. `/api/mcp` runs its Web Standard Streamable HTTP transport statelessly with JSON responses, so it fits a Vercel function. The package also lists Express and Hono as dependencies; we import neither.
- **Markdown: `react-markdown` with `remark-gfm` and `remark-breaks`** (MIT, unified collective), 2026-10-25. Long text people and agents write renders as GitHub-style Markdown, with a single line break kept. It builds React elements, never HTML strings: raw HTML shows as text and unsafe links are dropped. It renders on the server, so no parser ships to the browser. Main alternative: `markdown-it` (7 packages instead of about 100), but it returns HTML for `dangerouslySetInnerHTML`, where one changed option would open XSS.
- **Heading font: Be Vietnam Pro** (SIL OFL), 2026-10-25, replacing Outfit. Outfit has no Vietnamese glyphs, so marks like ế, ộ and ầ fell back to another font mid-word. Be Vietnam Pro is drawn for Vietnamese and keeps the soft geometric look; body text stays Inter, which already covers Vietnamese. Loaded with `next/font/google`, which downloads the files at build time and serves them from our own domain, so browsers never call Google; being OFL, the files can move to `next/font/local` if builds must not reach Google either. Weights 600 and 700 only. Alternatives: Lexend (closest to Outfit, but wider, so long Vietnamese titles wrap sooner), Plus Jakarta Sans, and Inter alone (no extra font, but headings lose their character).
